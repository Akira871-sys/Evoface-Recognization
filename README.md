🏢 AI 人臉辨識公司打卡系統 (Face Recognition Attendance System)
這是一個基於 Python 與 OpenCV 開發的自動化打卡系統，旨在透過生物辨識技術簡化公司考勤流程，並將數據結構化存儲於 SQLite 資料庫。

🚀 主要功能 (Key Features)
即時人臉偵測與辨識：採用 face_recognition 演算法，支援高準確度的即時比對。

自動考勤紀錄：辨識成功後自動判定「上班/下班」狀態並寫入資料庫。

重複打卡防止機制：內建緩衝時間限制（如 5 分鐘內不重複紀錄），避免重複數據。

本地資料庫管理：整合 SQLite，無需安裝大型資料庫軟體即可運行。

報表匯出功能：支援一鍵將打卡紀錄印出或匯出至終端機查看。

🖥️ UI 說明 (UI Overview)
本系統目前以 OpenCV 視窗 作為主要互動介面：

攝像頭畫面：即時顯示鏡頭影像。

辨識框 (Bounding Box)：

綠色框：辨識成功，下方顯示員工姓名。

紅色/白色框：未知人員，顯示 "Unknown"。

狀態提示：當打卡寫入成功時，終端機會即時噴出「✅ 成功為 [姓名] 紀錄」的訊息。

快捷鍵指令：

q：安全關閉程式並釋放攝影機。

r：在終端機印出所有歷史打卡紀錄報表。

⚙️ 工作流程 (Workflow)
初始化：程式啟動，載入 known_faces/ 資料夾下的特徵點。

掃描：開啟攝影機，逐幀偵測畫面中是否存在人臉。

比對：將偵測到的特徵與資料庫進行向量比對（歐幾里得距離）。

驗證：若信心值達標，進入資料庫寫入邏輯。

儲存：檢查是否符合打卡時間間隔，通過後寫入 timestamp。

❓ 常見問題 (FAQ)
Q1: 辨識速度太慢怎麼辦？

系統預設將影像縮小為 0.25 倍進行運算。若仍卡頓，建議減少 known_faces 中的照片數量或升級硬體。

Q2: 換了新員工怎麼加入？

只需將新員工的照片命名為「員工姓名.jpg」放入 known_faces/ 資料夾，重新啟動程式即可自動載入。

Q3: 如何防止別人拿照片打卡？

目前的基礎版僅進行特徵比對。若需防禦照片攻擊，需另外整合「活體檢測 (Liveness Detection)」模組。

Q4: 資料庫檔案可以移動嗎？

可以，只要確保 attendance.db 與 main.py 在同一目錄下，或在代碼中修改路徑即可。
